С компьютера или телефона на Xteink. По Wi-Fi.

Подключение

Откройте File Transfer на читалке и подключитесь к той же Wi-Fi сети.

Отправить файлы

Очередь пуста

Передача не конвертирует файлы. Форматы для чтения зависят от прошивки.

    На читалке

    /

    Подключите Xteink, чтобы выбрать папку и увидеть файлы на карте памяти.

      Как подключиться?
      1. На Xteink с CrossPoint откройте File Transfer. Оставьте этот экран открытым до конца передачи.
      2. Подключите оба устройства к одной Wi-Fi сети. Если используете точку доступа читалки, сначала откройте Полку, затем подключитесь к сети CrossPoint-Reader.
      3. Введите IP-адрес или ссылку с экрана читалки. Для точки доступа обычно используется .
      4. В Chrome разрешите сайту доступ к локальной сети. Нужна прошивка с поддержкой CORS; в старых версиях или других браузерах подключение может блокироваться.
      5. Выберите папку, добавьте файлы и нажмите «Отправить». Файлы с совпадающими именами не заменяются.

      Если соединение блокируется, откройте встроенный интерфейс читалки или используйте приложение для Android. Заводская прошивка Xteink не поддерживается.
