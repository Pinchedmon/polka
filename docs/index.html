Questions.

Which firmware do I need?

CrossPoint or inkMOD. The stock Xteink firmware has no file transfer API, so Polka can't talk to it.

The app can't find my reader

Make sure File Transfer is open on the X4 and both devices are on the same Wi-Fi. Some routers block discovery — then long-press the drawn reader and type the IP shown on the X4 screen.

Is there an iPhone version?

Not yet — Polka is Android only for now.

Android says the app is from an unknown source

That's normal for apps outside Google Play. The APK is built from the open source code on GitHub.
